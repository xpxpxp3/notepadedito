# Notepadedito
Android WebView 封装轻量记事本编辑器，将网页版HTML编辑器打包成安卓App。

## ✨ 项目特点
- 使用 WebView 加载内置HTML记事本，核心编辑逻辑在网页实现
- 支持文本行号显示、文本编辑、文件打开、文件保存功能
- Android原生权限处理，支持本地文件读写选择
- 适配安卓软键盘（持续优化滚动布局问题）

## 🛠 编译环境
- Android Studio Hedgehog / Iguana 或更高版本
- Gradle Kotlin DSL (`.kts`)
- 最小Android SDK：API 24（Android7.0）
